# 01. 다국어 모델(Multilingual Models)과 언어 불균형

## 📌 핵심 요약
> **인터넷 학습 데이터의 절반 가까이가 영어이기 때문에, 비영어권 언어는 모델 성능이 떨어지고 가드레일이 취약할 뿐만 아니라, 토큰화 비효율로 인해 사용 속도가 느리고 비용도 최대 10배까지 비쌉니다.**

---

## 1. 인터넷 데이터의 극단적인 영어 편향

* **Common Crawl(대표적 웹 크롤링 데이터셋)의 언어 분포 (Lai et al., 2023):**
  * **영어 (English):** 약 **45.88%** 차지 (압도적 1위).
  * **러시아어 (Russian):** 5.97% (2위, 영어의 약 $\frac{1}{8}$ 수준).
  * **독일어, 중국어, 일본어, 프랑스어, 스페인어:** 각각 4~5% 대.
* **저자원 언어(Low-resource Languages)의 소외:**
  * 펀자브어(1억 1,300만 명), 우르두어(2억 3,100만 명), 스와힐리어, 텔루구어 등은 화자 수가 매우 많음에도 불구하고 웹 크롤링 데이터 비율이 0.006%~0.02%에 불과하여 심각하게 과소대표(Under-represented)되어 있습니다.

---

## 2. 비영어권 언어에서 발생하는 4가지 주요 문제점

### ① 모델 성능 격차 (Performance Disparity)
* MMLU 벤치마크(14,000개 객관식 문제) 및 수학 문제(Project Euler) 테스트 시:
  * 영어는 매우 높은 정답률을 보이지만, 텔루구어, 마라티어, 펀자브어, 암하라어, 버마어 등에서는 정답률이 급락하거나 전멸합니다.
  * **원인:** 단순 학습 데이터 부족뿐만 아니라, 언어 고유의 문법 구조와 문화적 맥락의 차이도 학습 난이도에 영향을 미칩니다.

### ② "단순 번역 파이프라인"의 치명적 한계
> *"질문을 영어로 번역해서 LLM에 넣고, 나온 영어 답변을 다시 원래 언어로 번역하면 되지 않을까?"*
1. **번역 모델 자체의 한계:** 저자원 언어는 번역기 자체가 해당 언어를 정확히 이해하지 못함.
2. **정보 및 맥락 손실:** 예컨대 베트남어에는 화자 간의 상하 관계와 친밀도를 나타내는 복잡한 인칭대명사가 있으나, 영어로 번역되면 전부 'I'와 'You'로 뭉개지며 관계 정보가 소실됨.

### ③ 안전 가드레일(Safety) 및 오정보 필터링의 언어별 불균형
* **NewsGuard 실험 (2023):** ChatGPT-3.5에게 가짜 뉴스 작성을 요청했을 때:
  * **영어 프롬프트:** 7개 중 6개에 대해 생성을 **거부(Refusal)**함.
  * **중국어(간체/번체) 프롬프트:** 7개 모두 **가짜 뉴스를 그대로 생성**함.
  * 글로벌 LLM의 윤리/안전 필터가 비영어권 언어에서는 제대로 작동하지 않는 취약점이 존재합니다.

### ④ 토큰화(Tokenization) 비효율로 인한 속도·비용 불평등 ⭐

동일한 의미의 문장을 토큰화할 때 언어별로 생성되는 토큰 수가 극단적으로 차이납니다.

| 언어 (MASSIVE 데이터셋 기준) | 중간 토큰 길이 | 영어 대비 토큰 수 | 추론 지연시간 (Latency) | API 사용 비용 (Cost) |
| :--- | :---: | :---: | :---: | :---: |
| **영어 (English)** | **7** | **$1\times$ (기준)** | **기준** | **기준** |
| **스페인어 (Spanish)** | 유사 수준 | $\approx 1\times$ | 유사 | 유사 |
| **힌디어 (Hindi)** | **32** | **약 $4.5\times$** | 약 4.5배 느림 | 약 4.5배 비쌈 |
| **버마어 (Burmese)** | **72** | **약 $10.3\times$** | **약 10배 느림** | **약 10배 비쌈** |

* LLM API는 **토큰 수에 비례하여 과금**되고, 토큰을 한 개씩 순차 생성하므로 **토큰 수가 많을수록 응답 시간이 선형적으로 증가**합니다.

---

## 3. 해결책: 비영어권 언어 특화 모델의 등장

글로벌 범용 LLM의 한계를 극복하기 위해, 특정 언어와 문화권의 데이터에 집중하여 사전학습/미세조정한 **언어 특화 모델**들이 활발히 개발되고 있습니다.

* **중국어:** ChatGLM, YAYI, Llama-Chinese
* **프랑스어:** CroissantLLM
* **베트남어:** PhoGPT
* **아랍어:** Jais
* **한국어:** HyperCLOVA X, Solar 등
