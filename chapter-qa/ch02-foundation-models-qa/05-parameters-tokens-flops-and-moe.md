# 05. 파라미터, 연산량(FLOPs), MoE 희소 모델

## 📌 핵심 요약
> **파라미터는 AI의 가중치 숫자(다이얼)이며, 모델의 크기는 [파라미터 수(용량), 학습 토큰 수(지식량), 연산량 FLOPs(비용)]의 3대 지표로 측정됩니다. MoE는 일부 전문가만 활성화하여 거대 모델을 작은 모델의 속도와 비용으로 실행합니다.**

---

## 1. 파라미터(Parameter)의 정확한 개념

### (1) 직관적 비유
* 음악 믹싱 콘솔에 달린 **수십억~수천억 개의 미세 볼륨 조절 다이얼(Knobs)**.
* 완벽한 문장/답변을 만들어내기 위해 수조 번의 훈련을 거쳐 최적의 각도로 맞춰놓은 값.

### (2) 수학적 실체
* 함수 $y = Wx + b$ 에서의 가중치($W$, Weight)와 편향($b$, Bias).
* 컴퓨터 입장에서는 **행렬(Matrix) 속에 들어있는 수십억 개의 부동소수점 실수(Float 숫자)**들입니다.

### (3) 7B 모델의 VRAM 메모리 계산법
* 파라미터 1개를 16비트(2바이트, FP16/BF16) 소수로 저장할 때:
  $$\text{최소 GPU 메모리} = 70\text{억 개} \times 2\text{ 바이트} = 14\text{ GB}$$
* 즉, 모델 가중치를 GPU VRAM에 띄우는 데만 최소 14GB가 필요합니다.

---

## 2. MoE (Mixture of Experts, 전문가 혼합) 희소 모델

모든 파라미터가 매 단어마다 계산에 참여하는 밀집(Dense) 모델과 달리, 일부 파라미터만 켜지는 **희소(Sparse) 모델**입니다.

* **Mixtral 8x7B 구조:**
  * 7B 크기의 전문가 8명으로 구성.
  * 일부 파라미터를 공유하여 **총 파라미터 수는 46.7B**.
  * 매 토큰마다 **가장 적합한 2명의 전문가(12.9B 파라미터)만 활성화(Active)**.
* **MoE의 장점:**
  * 모델이 보유한 지식의 폭은 46.7B급이지만, **추론 속도와 연산 비용은 12.9B급 모델과 동일**.

---

## 3. 학습 데이터 규모: "토큰(Token)"의 중요성

* **샘플 수 ❌ vs 토큰 수 ⭕:** 문장 1개와 책 1권은 정보량이 완전히 다르므로, 데이터셋의 크기는 반드시 **토큰 수**로 측정해야 합니다.
* **Llama 시리즈의 학습 데이터 진화:**
  * Llama 1: 1.4조(Trillion) 토큰
  * Llama 2: 2조 토큰
  * Llama 3: **15조 토큰**
* **데이터셋 토큰 vs 학습 토큰:**
  * 1조 토큰 데이터셋을 2 에포크(Epoch, 전체 데이터 2회독) 돌렸다면 학습 토큰은 2조 토큰이 됨.
* **친칠라 법칙 (Chinchilla Scaling Laws):** 모델 파라미터만 키우는 것보다 충분한 양의 토큰을 학습시키는 것이 컴퓨팅 최적(Compute-optimal)입니다.

---

## 4. 컴퓨팅 연산량: FLOPs와 학습 비용 계산

### (1) FLOPs vs FLOP/s 개념 정리

| 용어 | 정의 | 역할 |
| :--- | :--- | :--- |
| **FLOPs (단위: FLOP)** | Floating Point Operations (부동소수점 연산 횟수) | 특정 모델 학습에 필요한 **총 연산량 (작업량)** |
| **FLOP/s (FLOPS)** | FLOPs per Second (초당 부동소수점 연산 횟수) | 하드웨어(GPU)의 **연산 속도 (성능 스펙)** |

### (2) GPT-3 (175B) 학습 비용 산출 공식 (예시)
* **총 필요 연산량:** $3.14 \times 10^{23}$ FLOPs
* **NVIDIA H100 256대** (대당 60 TFLOP/s) 기준 이론상 소요 시간: 약 236일 (~7.8개월).
* **실제 하드웨어 가동률(MFU, Utilization) 70%, 대당 시간당 $2 비용 적용:**
  $$\text{총비용} = \frac{\$2/\text{h} \times 256\text{대} \times 24\text{시간} \times 236\text{일}}{0.7} \approx \mathbf{\$4,142,811 \text{ (약 55억 원)}}$$

## 5. 모델 규모를 나타내는 3대 핵심 지표 요약

```
1. 파라미터 수 (Parameters)  ➔  모델의 잠재적 두뇌 용량 (Capacity)
2. 학습 토큰 수 (Tokens)      ➔  모델이 실제로 읽고 배운 공부량 (Knowledge)
3. 연산량 (FLOPs)             ➔  모델을 학습시키는 데 들어간 자본/비용 (Cost)
```

## 6. 역스케일링 (Inverse Scaling)

* **의문:** "모델이 커질수록 항상 똑똑해질까?"
* **현상:** 과도한 정렬(Alignment) 학습 시 특정 편향을 드러내거나 자의식을 주장하는 등 역효과 발생(Anthropic, 2022).
* **결론 (Inverse Scaling Prize):** 일부 특수 문제(단순 암기, 강한 사전 편향)에서 대형 모델이 일시적으로 실패하는 현상은 관찰되었으나, 현실 세계의 중대한 실패로 이어지는 사례는 드뭅니다.
