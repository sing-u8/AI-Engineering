# 04. 비교 평가(Comparative Evaluation)와 Elo/Bradley-Terry 랭킹 시스템

## 📌 핵심 요약 & 전체 맥락
> **"어떤 모델이 가장 좋은지 알고 싶다면 점수를 매기지 말고 맞붙여라(Comparative Evaluation)."**  
> 주관적이고 정답이 없는 생성 태스크에서, 각 모델에 독립적으로 점수를 매기는 단독 평가(Pointwise)보다 두 모델의 답변을 나란히 두고 우열을 가리는 **쌍체 비교 평가(Pairwise Comparison)**가 인간의 선호도를 포착하는 가장 직관적이고 강력한 방법입니다 (LMSYS Chatbot Arena).  
> 체스 레이팅에서 유래한 **Elo** 및 **Bradley-Terry 모델**은 수십만 건의 대결 데이터로 글로벌 리더보드를 구축하지만, **$O(N^2)$ 확장성 병목**, 가위바위보처럼 물고 물리는 **비이행성(Non-transitivity)**, 그리고 **승률 51%가 실제 비즈니스 ROI로 연결되지 않는 절대적 성능과의 괴리**라는 현실적 한계를 갖습니다.  
> 그럼에도 불구하고 비교 평가는 모델이 인간 최고 지능을 초월하는 초인공지능(Superhuman) 시대에도 인간이 유효한 피드백을 줄 수 있는 유일한 평가 수단으로 남을 것입니다.

## 1. 단독 평가(Pointwise) vs 비교 평가(Comparative) (pp. 148 ~ 150)

```
[ 댄스 경연 대회 비유 ]

• 단독 평가 (Pointwise) : 댄서 A가 혼자 춤추는 것을 보고 심사위원이 "8.5점"을 부여 ➔ 개별 채점 후 줄 세우기
• 비교 평가 (Comparative) : 댄서 A와 B를 무대에 나란히 세워놓고 "누가 더 잘 추는가?" 투표 ➔ 승패 기록으로 레이팅 산출
```

### ① 왜 비교 평가가 더 직관적인가?
* 음악, 에세이, 디자인처럼 주관적인 품질을 가진 대상은 **"절대 점수를 매기는 것(Pointwise)"**보다 **"둘 중 나은 것을 고르는 것(Comparative)"**이 인간 평가자에게 훨씬 쉽고 일관성이 높습니다.
* **Anthropic (2021):** LLM 평가에 비교 평가를 최초로 도입하여 모델 정렬(RLHF)에 활용.
* **LMSYS Chatbot Arena:** 일반 대중의 블라인드 비교 투표를 크라우드소싱하여 AI 생태계에서 가장 신뢰받는 글로벌 리더보드로 등극.
* **프로덕션 적용 (Figure 3-10):** ChatGPT 등 상용 서비스는 사용자에게 두 답변을 나란히 보여주고 선호하는 쪽을 고르게 하여 고품질 피드백 데이터를 실시간 수집함.
* 💡 **무승부(Ties) 허용의 중요성 (p. 149):** 두 답변이 둘 다 완벽하거나 둘 다 똑같이 엉망일 때 무승부를 허용하지 않고 강제로 승자를 고르게 하면 **평가 데이터에 극심한 무작위 노이즈가 유입**됩니다.

```
[ 비교 평가 vs A/B 테스트의 차이 ]
• A/B 테스트   : 사용자는 한 번에 모델 A 또는 모델 B 중 1개의 출력만 경험함.
• 비교 평가     : 사용자가 모델 A와 모델 B의 출력을 동시에 나란히 보고 직접 선호도를 선택함.
```

---

### ② ⚠️ 선호도 투표를 적용하면 안 되는 위험한 영역 (pp. 149 ~ 150)
1. **정확성(Correctness)이 본질인 사실적 질문:**
   * *"전자파와 뇌종양 사이에 연관성이 있는가?"*, *"어려운 수학 미적분 문제의 해는?"* 같은 질문을 선호도 투표로 처리하면, 비전문가 사용자가 **틀렸지만 말투가 친절하고 긴 오답에 투표**하여 모델에게 치명적인 왜곡 신호(Misaligned Signal)를 학습시킵니다.
2. **사용자 경험(UX) 훼손:**
   * 사용자가 자기도 정답을 몰라서 AI에게 물어봤는데, AI가 두 개의 서로 다른 답을 내놓고 "둘 중 골라보세요"라고 되물으면 극심한 피로감을 유발합니다.
   * 따라서 비교 피드백은 사용자가 결과를 쉽게 검증할 수 있는 **'보조/인턴' 역할의 태스크(코딩, 번역, 문장 교정)**에 적합합니다.

> 📖 **도표 참고:**
> * **[Figure 3-10 (p. 149)]**: ChatGPT가 동일한 프롬프트에 대해 두 개의 응답 초안을 나란히 제시하며 사용자에게 선호도를 묻는 실제 인터페이스 화면.

### ① 체스 레이팅의 도입: Elo vs Bradley-Terry
* **Elo Rating System:** 체스, 축구, e스포츠에서 1세기 동안 사용된 표준 알고리즘. (단점: 대결 순서와 평가자 등장 순서에 점수가 민감하게 흔들림).
* **Bradley-Terry 모델 (Chatbot Arena의 공식 표준):**  
  LMSYS는 Elo의 순서 의존성을 극복하기 위해 전체 대결 데이터를 종합하여 각 모델의 숨겨진 실력 파라미터($\beta_i$)를 **최대우도추정법(MLE)**으로 계산하는 Bradley-Terry 모델로 전환했습니다.
  * 모델 A가 B를 이길 확률 수식:
$$P(A \gg B) = \frac{e^{\beta_A}}{e^{\beta_A} + e^{\beta_B}} = \frac{1}{1 + e^{-(\beta_A - \beta_B)}}$$
* 💡 **Bradley-Terry 점수의 Elo 스케일링 (각주 23):**  
  사용자들에게 친숙함을 주기 위해 Bradley-Terry 점수를 $\beta \times 400 + 1000$으로 스케일링한 뒤, **`Llama-13b` 모델의 점수를 정확히 800점으로 맞추는 정규화**를 거쳐 표시합니다.

## 3. 비교 평가의 3대 도전 과제와 한계 (pp. 152 ~ 155)

---

### ① 확장성 병목 (Scalability Bottlenecks)과 비이행성 (Non-Transitivity)
* **$O(N^2)$ 대결 수 폭증:**  
  모델 수가 57개만 되어도 대결 쌍은 **1,596개**로 늘어납니다. 2024년 1월 LMSYS가 244,000건의 비교를 수집했으나, 대결 쌍당 평균 153건에 불과했습니다.
* **이행성(Transitivity) 가정의 붕괴 (가위바위보 현상, p. 152):**  
  * 알고리즘은 $A > B$이고 $B > C$이면 당연히 $A > C$일 것이라 가정합니다.
  * 학술 연구들(Boubdir et al., Balduzzi et al., Munos et al.)에 따르면, 인간의 선호도는 비이행적이며 **코딩은 A가 이기고, 번역은 B가 이기고, 추론은 C가 이기며 가위바위보처럼 순환(Non-transitive)**하여 순위 왜곡이 발생합니다.
* **해결책 (Active Matching):** 무작위 대결 대신, **전체 랭킹의 불확실성을 가장 많이 줄여주는 대결 쌍을 능동적으로 선별(Sampling)**하는 알고리즘 도입.

---

### ② 크라우드소싱의 품질 관리 및 표준화 부재 (pp. 153 ~ 154)
* **대중의 팩트체크 부재:** 일반 사용자는 검증 없이 문체가 번지르르하고 친절한 답변에 묻지마 투표를 던질 위험이 큼.
* **단순 프롬프트 편향:** 복잡한 RAG나 실무 프롬프트 대신, `"X에게 3명의 자매가 있고..."` 같은 단순 퀴즈가 **44번이나 중복 입력**되는 등 현실 업무와의 괴리 발생.
* **해결책:** LMSYS는 내부 모델을 이용해 **'고난도 프롬프트(Hard Prompts)'**만 필터링하여 순위를 별도 산정하고, Scale AI는 훈련된 전문 평가자 기반의 프라이빗 리더보드를 운영함.

---

### ③ 상대적 승률과 절대적 비즈니스 가치(ROI)의 괴리 (p. 155) ⭐

```
[ B가 A를 상대로 승률 51%를 기록했을 때의 3가지 시나리오 ]

1. Model B는 훌륭하고, Model A는 형편없다.
2. Model A와 Model B 둘 다 훌륭하다.
3. Model A와 Model B 둘 다 형편없다 (도토리 키재기).
```

* **비즈니스 가치 예측 불가:**  
  고객센터 봇으로 Model A(티켓 70% 해결)를 쓰다가, A를 상대로 승률 51%를 기록한 Model B로 교체할 때 **티켓 해결률이 몇 %나 오를지는 비교 평가만으로 알 수 없습니다.**
* **ROI 분석 불가:**  
  만약 Model B의 API 비용이 A보다 2배 비싸다면, **단 1%의 승률 향상이 2배의 비용을 정당화하는지 판단할 수 없으므로 반드시 절대 평가(Exact/Business Eval)가 병행**되어야 합니다.

## 4. 비교 평가의 미래와 Chapter 3 총결론 (pp. 155 ~ 156)

### ① 비교 평가가 여전히 대체 불가능한 3가지 이유
1. **초인공지능(Superhuman) 시대의 유일한 평가 수단 (Llama 2 논문 인용, Touvron et al. 2023):**  
   모델이 최고 인간 전문가의 지능을 넘어서는 작문이나 추론을 할 때 절대 점수 채점은 불가능해지지만, **두 답변을 놓고 비교하는 것은 인간이 여전히 훌륭한 피드백을 제공**할 수 있습니다.
2. **벤치마크 포화(Saturation)가 없음:** 고정된 시험지는 만점이 나오면 버려지지만, 대결 시스템은 더 강한 모델이 나오면 끝없이 진화합니다.
3. **치팅(Cheating) 불가:** 정답지를 외우는 식의 데이터 오염(Contamination)이 불가능하여 리더보드 신뢰도가 가장 높습니다.
